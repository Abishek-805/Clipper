# Task 06H — Evidence-Grounded Story Graph and Intelligent Moment Reasoning

## Result

Task 06H adds a deterministic, persistent episode evidence graph and a separate human review board built from the existing Task 06F and Task 06G caches. It does not alter production clip selection, captions, rendering, queue behavior, or the desktop GUI.

The graph records source evidence separately from interpretations. The cached Qwen outputs remain unverified, reported model confidence is preserved in its own field, transcript wording is retained verbatim from the cached Whisper analysis, and every claim and relationship points to evidence IDs. The review board makes comparisons practical and links each moment to the original local source at its start time.

**Editorial acceptance remains incomplete.** The graph abstained from recommending clips because the review dataset contains no human annotations. This is an honest zero recommendation result, not a claim that the episode has no good moments.

## Implementation

### Persistent evidence graph

`evaluation/story_graph.py` builds and validates schema `clipper-evidence-story-graph-v1`. Stable IDs derive from the source fingerprint and record identity. Graph cache identity records source fingerprint, model/runtime, window IDs, transcript fingerprint, and sampled frame timestamps. The builder rejects mismatched source fingerprints, invalid intervals, missing claim evidence, dangling node references, duplicate IDs, and relationships without valid evidence.

For the cached S01-E01 source, the graph contains:

- 13,004 evidence records, including cached frames, exact transcript words and turns, subtitle cues, scene intervals, cached signals, and raw model observations.
- 1,491 nodes, including 388 scenes, dialogue turns, phrases, 131 event proposals, anonymous per-window entity hypotheses, and 28 Task 06F comparison candidates.
- 1,201 model-interpretation claims. All remain `unverified`; none is human-confirmed.
- 1,446 evidence-backed relationships, including chronology, scene membership, possible question-response links, lexical callback candidates, and candidate overlap links.
- 115 cross-scene callback candidates. They remain `possible_callback_to` hypotheses based on the existing Task 06F lexical analysis; lexical overlap is not treated as proof of a plot reference.
- One possible cross-modal disagreement flag for instructional skill dialogue paired with an action label. It is a review flag, not an automatic contradiction verdict.

The graph does not merge entities between windows. Visual names and nearby transcript names are not treated as identity evidence. Speaker diarization remains unavailable. Dialogue turns, phrases, and Task 06F moment quotations are checked against the overlapping cached word timestamps before being persisted; an unmatched quote fails graph construction. Exact quotations are stored as transcript evidence, not regenerated by a model.

### Action and hallucination controls

All 108 cached Task 06G windows contain an `actions` list, while only 11 are categorized as `action`. The graph does not turn an aggregate window-level action list into a temporal action sequence. The cached results lack frame-local action labels, so the episode graph classifies no window as a verified fight; its fight progression is `unknown_event` unless a future provider supplies distinct timestamp-local observations. A static sword pose, an action word, a glowing image, or dialogue about combat cannot independently establish a fight.

The known unsupported flying and spell-casting descriptions remain separate unverified claims. Model confidence values such as 0.95 are retained as `model_reported_confidence` and are not used as calibrated correctness or as an editorial ranking score. The transcript and visual claims remain separate when they disagree.

### Dialogue, boundaries, and global assessment

The graph includes word-level transcript evidence, cached utterance/turn records, important phrase records with overlapping word evidence, available subtitle cues, and the existing Task 06F question/response and possible callback links. Possible responses and callbacks remain unverified; a following sentence or repeated word is not considered proof.

Task 06F moment boundaries are carried forward with their existing transcript-based boundary explanation and source interval. Qwen window intervals are explicitly marked `SOURCE_WINDOW_ONLY`; they are not presented as editorial boundaries. Short moments are not padded to a fixed duration.

The global editorial result is `NOT_ASSESSED_NO_HUMAN_GROUND_TRUTH`, with **zero recommendations**. The system keeps all 136 review moments available instead of promoting activity scores or raw model confidence to editorial quality. This branch does not claim an episode-level ranking is editorially accepted.

### Review board and annotations

The new `candidate_review_06h/` output contains `story_graph.json`, `anime_highlight_dataset.json`, `index.html`, and `build_metrics.json`. The board contains 136 cards:

- 28 existing Task 06F review candidates, including all five previously selected production clips.
- 108 chronological cached Qwen windows.

Each card has three representative cached frames and a link to open the original local video at the source start timestamp. Existing cached previews are reused where present; no new preview video or final Short was rendered. The board adds a chronological graph view and a tentative relationship view. Reviewers can keep/reject/maybe, correct category and boundaries, record exact dialogue corrections, unsupported claims, missing context/payoff, notes, and reviewer identity. Existing annotations are preserved when the source and candidate intervals match; the existing source-fingerprint and interval checks remain in place.

The browser review board was generated and its frame/preview references were checked against disk. It was not visually inspected in a browser during this task.

## Limitations and next acceptance work

- No new Qwen inference was run. Task 06H uses cached Task 06G outputs only; bounded graph-reasoning inference and prompt/completion measurements for new reasoning are not available.
- Existing per-window descriptions do not contain frame-local action stages. Real temporal fight verification, preparation/attack/impact/reaction reconstruction, and non-verbal event recall remain unproven.
- Relationship candidates are sequence/lexical hypotheses. Cause/effect, plot callbacks, answer relationships, and character identity need evidence review or bounded model analysis followed by human validation.
- Cross-modal conflict detection is a narrow deterministic flag, not general contradiction detection.
- There are zero human annotations, so precision, category agreement, boundary accuracy, recall, and editorial usefulness are unmeasured. Do not use the graph as an accepted automatic selector.
- Original-source playback depends on Windows/browser handling of local file URLs. Asset references were checked, but browser interaction was not manually verified.
- Production candidate scoring, UI, renderer, captions, queue, and Task 07 remain untouched.
